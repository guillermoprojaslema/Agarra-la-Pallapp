1. **Buscar ofertas** → se listan y guardan en [`ofertas/pendientes.md`](ofertas/pendientes.md).
2. **Postular** (ej. «postula a OF-…») → se adapta el CV, se registra en este README y, con confirmación, se postula con el navegador.
